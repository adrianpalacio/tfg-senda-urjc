# Fase 4 — Validación y prototipos

## Prototipos navegables

Cada configuración del estudio produjo un prototipo del sistema. Son ficheros HTML
autocontenidos (sin dependencias externas): se descargan y se abren con doble clic en
cualquier navegador.

- `prototipo-tradicional/index.html` — elaborado a mano por el analista sobre los
  requisitos validados con el cliente
- `prototipos-llm/chatgpt.html`, `prototipos-llm/gemini.html`,
  `prototipos-llm/claude.html` — generados por cada modelo a partir de su propia
  especificación (prompts P14 y P15)

En el prototipo de ChatGPT, el nombre del usuario de ejemplo se ha anonimizado
respecto a la salida original del modelo; el resto del contenido es la salida bruta.
